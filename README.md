# Spy Game (برا الموضوع) 🕵️‍♂️

A digital local-multiplayer party game inspired by "Spyfall", fully developed using the Godot Engine. 

## About The Game
Players are given a secret location and a role, except for one player who is randomly chosen as the "Spy". Through questioning, players must identify the Spy, while the Spy tries to guess the location. The game handles role distribution, turn management, and secret UI reveals.

## Technical Focus
This project demonstrates proficiency in:
* **UI/UX Management:** Extensive use of Godot's Control nodes (Containers, Buttons, Labels) to create a smooth, responsive, and intuitive interface for passing the device between players.
* **Game State Management:** Handling transitions between different game phases (Setup, Role Reveal, Timer, Voting).
* **Data Handling:** Dynamic loading and randomizing of locations and roles using GDScript.

## Tech Stack
* **Engine:** Godot Engine
* **Language:** GDScript
